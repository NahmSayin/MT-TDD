# MT-TDD — a .NET sandbox for practising Test Driven Development

A deliberately tiny .NET solution for learning TDD and DotNet.

## Prerequisites

The .NET SDK (this was built against .NET 10). Check what you have:

```bash
dotnet --version
```

If that fails, install from https://dotnet.microsoft.com/download.

## Running the tests

From the repository root:

```bash
dotnet test
```
